# Storyboard AI - GenAI Pipeline

This directory contains the core generation pipeline that automates the process of converting a topic or instruction set into a fully animated, narrated, and subtitled storyboard video.

## Who Generates the Story?

The story (narrative structure, pacing, script narration, scene breakdown, and visual prompts) is generated by the **Director** module.
* Located in: [director_tool_fn](file:///d:/software-dev/storyboard-ai/genai-pipeline/tools/director.py#L7) inside `tools/director.py`
* The Director receives the user's instructions and optional research reports, plans the global metadata (tone, audience, pacing, narrative persona), and breaks down the project into individual scenes.

---

## High-Level Pipeline Architecture

```mermaid
graph TD
    User["User Input (Topic / Context)"] --> Research["1. Research (Deep or Web-Grounded)"]
    Research --> Director["2. Director Planning (director.py) <br/><i>Generates Global Plan & Scenes</i>"]
    
    subgraph Scene_Processing ["3. Scene Generation (Iterated for Each Scene)"]
        Director --> RefSearch["3a. Reference Image Search"]
        RefSearch --> PromptGen["3b. Image Prompt Generation"]
        PromptGen --> ImageGen["3c. Image Generation (Imagen)"]
        
        ImageGen --> VeoGen["3d. Veo Video Generation (Optional)"]
        ImageGen --> SAM["3e. SAM Segmentation"]
        SAM --> DrawingAnim["3f. Whiteboard Drawing Animation"]
        
        DrawingAnim & VeoGen --> ConcatSilent["3g. Combine Drawing + Veo Videos"]
        ConcatSilent --> RefineNarr["3h. Refine Narration Script (Fit to duration)"]
        RefineNarr --> TTS["3i. TTS Audio Generation"]
        TTS --> AudioMerge["3j. Merge Audio & Video"]
        AudioMerge --> Transcribe["3k. Transcribe Audio"]
        Transcribe --> Subtitles["3l. Burn Subtitles into Video"]
    end
    
    Subtitles --> FinalMerge["4. Final Assembly (Concatenate all scenes into story.mp4)"]
    FinalMerge --> FinalVideo["Final Storyboard Video"]
```

## Running the Pipeline

You can run the pipeline using `pipeline.py`:
```powershell
python pipeline.py
```
And follow the interactive prompts to choose the research mode, fast mode, narration language, and whether Google Veo video generation is enabled.
